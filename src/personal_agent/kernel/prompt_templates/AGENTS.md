# 生产 Prompt 模块规范

> 本文件适用于 `src/personal_agent/kernel/prompt_templates/**`，继承根 [AGENTS.md](../../../../AGENTS.md)。修改前必须完整阅读[生产 Prompt 通用契约](../../../../docs/devSpec/code-structure.md#6-生产-prompt-是版本化代码契约)；本文只规定注册、输入序列化和模块验证。

## 1. 唯一注册与生产消费

每个生产 Prompt 必须定义为 `PromptSpec`，使用稳定且带职责范围的名称，并由 `personal_agent.kernel.prompts` 唯一注册。

- 调用方必须从注册表取得模板和版本，并将版本写入模型请求和追踪记录。禁止复制正文、另写版本、创建旁路注册表或保留新旧 Prompt fallback。
- 本模块只拥有模型指令和边界输入的序列化；业务事实、权限、执行、状态迁移、预算和完成判断由各自确定性责任主体拥有。

## 2. 结构与输入边界

中文表达、结果契约、分区、分类规则与示例均遵守通用契约，不在本模块重复定义。

动态输入必须使用可机械解析的稳定结构，并明确其中内容是数据而非指令；禁止靠模糊标题、字符串拼接顺序或自然语言猜测区分用户内容、证据和规则。仅迁移存量 Prompt 时必须保持实际发送字节不变，已知语义缺陷继续留在准入队列。

## 3. 版本与验证

改变模型输入分布、字段语义、决策顺序或示例时，必须提升 `PromptSpec.version`。声称格式化或迁移保持字节不变时，必须由确定性测试证明。

- Contract 检查注册、版本、输入往返、输出 schema，以及调用方消费同一模板版本。
- 真实模型评测和 Product E2E 按通用契约分工，不能互相替代。
- 候选未达预声明门槛时，删除候选正文、版本及专用评测入口；不得保留 flag、fallback 或另一个隐式生产入口。
