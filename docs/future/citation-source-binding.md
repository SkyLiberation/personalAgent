# 引用来源修复的剩余验收

准入状态由[设计队列](design-optimization-backlog.md)唯一拥有。正式研究第十八稿证明逐行引用遗漏已有来源；[过程记录](../optimization/citation-source-attribution.md)保存失败与局部证据，[ADR 0028](../adr/0028-preserve-citation-source-binding.md)保存责任和取舍。

唯一修复边界是执行来源到引用证据的确定性投影。原 Conversation 的引用物化、局部和整稿核验消费该投影，来源权威不转交模型。目标是保持已读原文的来源、身份、版本、位置与拒绝边界；不同来源、不同版本、未知和冲突来源属于必要反事实。

剩余门禁是同一正式入口的真实用户结果与因果回归。本轮按用户要求优先收束局部验证，不重复长 E2E，不能将该门禁记为通过。相邻独立阻塞处理后，恢复原中文请求与用户结果契约的正式验收；不能注入固定 Final 或指定引用路径制造 E2E。来源错绑、原文或覆盖事实变化、无据结论因来源字段被放行时撤回对应修改；独立失败不扩大为来源丢失的反例。
