# 原文行号与临时引用编号混用

**独立问题 `CITATION-COORDINATE-CONFUSION-001`：2026-09-18 的新协议正式运行提交了目录外编号 `e1698`；相关原文恰好位于第 1698 行，且同一位置被分配了三个不同编号。** 非法引用和重复身份是已确认事实，模型混淆两种编号是待验证解释。文档坐标替换已进入目标代码，本轮按用户要求只进行 Offline 验证，尚未达到长期固化条件。准入状态由 [Future 队列](../future/design-optimization-backlog.md)拥有，措施及验收条件由[独立设计](../future/citation-coordinate-identity.md)拥有。

## 变更前协议的失败事实

原中文研究任务的第五稿在 `runtime-verify-45` 提交 12 个引用，其中 `e1698` 不在当时的 `e1` 至 `e1264` 目录。运行系统按 `citation_source_unavailable` 拒绝，尚未进入这一稿的语义核验。原始结果是运行中断、未交付，不能把本次编号拒绝直接当成整轮终止原因。正式用户结果见[评测登记](../evals/02-current-case-inventory.md#同代码重新验证核验反馈与修订)，原稿与反馈见[拒绝记录](../../.tmp/verifier-e2e-rerun-20260918/decision-feedback.json)。

提交前 `0032.json` 的重建目录中，同一 OpenAI 文档版本的第 1698 行对应 `e587`、`e683`、`e1037`，原文和来源一致。实际输入物化与引用绑定重建的目录一致，相关证据没有在该构造路径中丢失。源码按归档身份核对；本次属于历史输入重建，不是独立捕获的模型请求，也没有观察模型内部推理。

变更前 `_catalog` 每遍历一份成功观察及其返回行就递增编号，未按文档版本和原文范围合并引用身份。重复读取产生不同执行记录是合理的，但同一原文位置因此产生不同引用身份没有必要；这增加了阅读坐标与引用编号之间的对应关系。代码坐标见[引用物化](../../src/personal_agent/application/conversation/citations.py)，该审计绑定变更前源码，不可在新代码上覆盖重跑；历史审计见[脚本](../../.tmp/citation-coordinate-confusion-20260918/audit.py)及[报告](../../.tmp/citation-coordinate-confusion-20260918/audit.json)。

## 优化措施与因果边界

采用的设计方向是让搜索、读取和引用使用同一文档坐标，例如 `d3:1698`。Artifact 文档编号绑定确定版本的 `ResourceRef`，内联结果绑定来源与内容摘要；同版本同范围重复返回沿用引用身份，部分长行保留列范围。运行系统仍只恢复实际可见、已返回的证据，模型负责选择支持正文的内容。已删除逐观察累加的行引用编号及完整结果号，不增加模型调用、第二套引用表或自动补引；当前契约见 [ADR 0030](../adr/0030-document-line-citation-identity.md)。

该方向能确定性消除同一位置的重复身份及行号到另一套序号的转换，但是否降低模型错引概率仍须验证。它不自动修复漏引、无据结论、来源支持误判或重复读取行为。2026-09-15 旧复合观察坐标的失败已经过期，不并入本问题的 baseline 或复现次数；本项也不重新打开已经成立的来源保真和核验意见绑定修复。

## 统一所有生成端引用为文档行坐标

**2026-09-22，用户明确要求消除两种并存的引用格式。** 原实现仅统一逐行引用，仍为整条工具结果生成 `rN`；近期修订输入中的 `r9`、`r21` 分别是 MCP 概述与 Tools 页面的完整返回，属于当前代码主动提供的合法选项，不是模型自行使用过期编号。原 ADR 0030 对完整结果号的保留决定在本轮被替换，历史原始归档不改写。

本轮先隔离三个生产文件：引用目录与模型投影、共享引用类型、Final Prompt。所有可引用内容只暴露 `dN:行号`，部分长行仍保留实际列范围；旧 `rN` 在类型和目录均拒绝，不自动转换。完整内联网页使用其原文行，URL 与正文摘要区分来源快照；其他工具结果按明确的 JSON 结果文档分行，标记为 `tool_result`，不能冒充网页原文。Artifact 窗口继续使用资源版本和原文行，同一来源快照或窗口重复读取复用坐标。

Journal 与 Artifact 继续拥有原始事实，`citations.py` 唯一分配可见文档号和恢复引用；文档号及内联摘要是可重建投影，不增加存储或虚构可读取的 Artifact。来源类型保持 URL、行及列；Artifact 使用 `resource_ref`，内联内容使用 `content_digest`，二者互斥。新增一个只读行投影类型，供模型只接收一次正文；绑定侧仍保留完整来源。删除整条 `evidence_id` 字段及 `rN` 指令，查询、续读和截断事实保留。不能为统一形式引用未返回的卸载正文。

验证先回放近期修订的原始工具事实，逐行核对新目录、实际模型视图和绑定来源；检查原 `r9`、`r21` 内容完整保留、重复来源、不同版本、部分行及不可见范围。旧稿含旧编号，不将其静默迁移成当前协议；后续修订验证需重新生成当前协议的稿件。随后最多两次真实 MiMo 短样本，分别检查 MCP 同意要求与搜索摘要边界，采用生产 Prompt、Schema、输入投影和绑定。预声明最多 30,000 tokens，每次 180 秒、输出 4096、零重试；预计 15,000 至 25,000 tokens、1 至 4 分钟，单价未知。单次超过 60 秒复核，结构、来源或保真失败停止，不补抽。

本轮沿用用户对引用改造的 Offline 范围，不启动 E2E 或单元测试；完整产品结果及长期观察另行验收。引用坐标的外部依据沿用 ADR 0030 已固定的两个 A 级读取实现，不据此推断它们统一所有工具返回。预声明、双格式基线与源码保存于[本轮归档](../../.tmp/unified-citation-lines-20260922/plan.json)。现已按验证结果替换三个生产文件，净增 43 行；Final Prompt 为 `v18-unified-document-citations`，此前自检和修订行为保持。没有接入其他隔离修订候选。

历史回放的 22 条原始执行观察中，原目录含 21 个完整结果号。新目录全部 1401 条返回行可恢复到原文及来源，其中原有 842 条 Artifact 窗口行内容和来源坐标保持。原 `r9`、`r21` 对应网页分别恢复为 79、304 条原文行。重复来源、不同 URL 或正文快照、搜索查询与证据分离、部分列及不可见范围检查通过；`r9`、`r21`、`e1698` 均被类型拒绝。模型投影与绑定目录一致，Journal 原值不变。该回放使用历史执行事实及派生反事实，不重放旧编号稿件，不是新的 E2E。
