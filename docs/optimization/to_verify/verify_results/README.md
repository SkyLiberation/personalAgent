每条记录按原任务、源码、配置、材料和预算身份解释。历史计划不作为新的启动指令，局部通过不提升为完整产品通过。已撤销的下载／打包门槛及未知用量单独停止规则只供追溯，当前契约以对应设计和专题为准。

正式成绩、费用口径和发布限制仍由[评测盘点](../../../evals/02-current-case-inventory.md)拥有；本目录不另建成绩台账或准入队列。原始请求、执行、SDK、日志与 checksum 保持在原封存位置，不因文档拆分修改其内容或校验和。

正文更新、候选保留与关闭继续遵守[文档规范](../../../AGENTS.md)及[优化记录规则](../../README.md)。新增记录按实际问题组织；同一事实只在一处解释，设计和其他记录通过链接引用。
