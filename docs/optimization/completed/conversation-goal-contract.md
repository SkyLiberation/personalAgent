# 执行目标工具的单一正文契约

2026-11-02，目标工具结构简化已完成。关闭范围仅为重复语义字段和目标内成果引用；用户要求遵循及核验漏放仍由[目标维护 Spec](../to_verify/analysis-goal-maintenance.md)跟踪，真实成绩由[验证记录 §29](../to_verify/verify_results/analysis-correctness.md#29-单一目标正文与取消成果引用后的前三轮)拥有。

## 问题与采用决定

原工具让模型分别填写整体目的、有效要求、本轮任务和可选成果编号。前三项由同一模型一起消费，已有实际目标重复描述敏感性检查；成果引用只被目标准入、保存和展示消费，原材料和工具历史已经拥有资源引用，没有据此加载成果或完成核验的独立路径。保留四项增加模型需要填写和维持一致的内容，不能证明持续遵守用户要求。

目标工具现在只接收一个完整 `objective` 正文。具体本轮交付及仍有效的条件关系由模型依据原话写入正文，允许按需 Markdown 组织。材料和成果继续由原输入、工具回执、Artifact 与历史提供。字段定义及每轮维护、沿用、读取和版本规则只由[唯一契约](../to_verify/analysis-goal-maintenance.md#4-事实归属与最小契约)拥有，此处不再维护第二套参数说明。

## 失败尝试与边界

首次 gr644 在单正文目标成功保存后，因 Docker Desktop 未运行导致评测数据库连接超时，首次工具执行前 HTTP 500；2 次物理调用、20,775 tokens 保留。[环境定位](../../../.tmp/gr644/environment-failure.json)与原封存未改写。恢复依赖后，gr645 使用完全相同生产源码重新从第一问执行，没有把失败运行的目标或答案交给模型。

本次结构简化没有修复所有语义问题。第三轮目标新增“恰好三个”，没有保留原话中的不足可少报例外；回答反向解释 genre focus 的集中度含义，并将美国列入主名单，目标核验仍放行。独立评分和整体用户结果由验证记录单独报告，不能用结构审计覆盖。

## 重新打开条件

新的真实 E2E 或其真实阶段产物表明：单正文协议丢失现有接口必须消费的信息、维护及版本接续失败，或已有资源无法通过原工具与历史恢复时，重新审查对应最早边界。普通语义判断错误不能单独证明必须恢复多字段目标或成果列表；新增结构仍须说明实际消费者与最小必要性。
