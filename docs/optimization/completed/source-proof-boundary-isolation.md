## 问题与机制

正式中文运行 `irun_136c545f011740b3` 的 c4 只引用两项动作与目的，却把它们概括为客户端 SHOULD 建议；必要的客户端主体及程度引导句位于已返回 d5:295，没有绑定本条引用。原 Source 同时看到整个返回目录，便把已看到的前提当作已经提交的引用支持。用户没有要求机械引用某个标题行，但研究来源支持契约要求语义必要前提进入本条证明。

旧隔离候选将返回范围与引用支持分成两次请求，七项按其原身份通过；它没有证明必须增加一次核验。用户撤回该分工后，统一六类承担两种证据用途。Runtime 已有 `resource_ref` 和 `content_digest` 定位材料快照，`tool_result` 与网页正文来源仍各守其身份；同快照或 URL 出现不能自动证明指定网页正文支持。旧双阶段代码、输入及结果仅用于历史反查，不是现行生产路径。
