## 问题与采用方案

Source 曾因草稿没有显式排除补充输入流程而要求澄清用户授权，尽管原文没有建立两者的对应关系。收窄必要澄清后，A6 又用全部返回目录的第40、302行代替本条引用，返回空发现。目录中的原文真实存在，但当前论断引用尚未支持所述关系；应报告引用缺证，不能称原文没有取得。

采用方案只统一现有 Source 的任务定义：外部事实检查 `execution_evidence` 的本条引用支持；关于取得或返回范围的表述检查 `returned_evidence` 的实际范围。澄清针对实际断言必需且确实未定的关系，不因相近用词、其他动作或未显式排除产生新疑点。全部真实输入保持，模型一次判断、直接输出类别和同一项说明；Runtime 校验身份与恢复原文，既有 selector 和 writer 消费。

保留五字段五类，未增加字段、状态、模型阶段或调用。相对 v18 仅修改既有目标及两处宽泛材料措辞；该候选源码文件净增74字，前一必要澄清句净增13字。完整业务消息和 Schema 原生对照3/3，标签未进入被评请求。
