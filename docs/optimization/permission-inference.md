## 10. 同次生成中绑定论断与来源

**2026-09-09 本轮试验单次生成的输出契约，不继续删除上下文或追加范围提醒。** 第 8、9 节的失败证明完整自由正文仍会错配属性和扩大总结。新的隔离候选要求模型直接输出可展示的论断单元，每个单元同时给出依据引用或本次未确认状态；代码只校验引用坐标并逐项展示原文字段，不另调用模型生成第二份正文。全部原文仍在输入，不先筛资料或输出一份独立事实摘要。

两个 A 级机制坐标于本轮核对：[Anthropic Citations](https://platform.claude.com/docs/en/build-with-claude/citations) 的文本块与引用、文档位置、可引用内容章节，以及 [Google Firebase GroundingSupport](https://firebase.google.com/docs/reference/android/com/google/firebase/ai/type/GroundingSupport) 的 `GroundingSupport.segment` 与 `groundingChunkIndices`。前者将响应文本块绑定具体来源位置，并由服务提取原文；后者将输出片段关联到来源块。这里只采纳论断与原文位置的直接关联，不复制服务方原生引用能力、置信分数、搜索服务或新调用阶段。Anthropic 明确原生 citations 与其结构化输出不兼容，本轮是 MiMo 上自有隔离 JSON 协议，不能冒充同一 API 或外推其可靠性保证。两份官方内容及哈希已保存到本轮测试目录。初选的 Google REST 旧链接重定向后没有目标字段，改用可直接核对的 Firebase 官方 SDK 文档；不以旧搜索摘要代替原文。外部机制不证明本候选有效。
