## personalAgent 的同场景路径

- **入口与发送前压缩。** `POST /api/conversation/turns` 经 `Runtime.converse` 进入 `ConversationService.respond`。Runtime 提供模型客户端、Journal 和 Artifact 服务，ConversationService 装配 `HistoryCompactor`。主决策 `_decide` 先构造可发送请求，适配器用实际序列化形状计量消息和工具定义。压缩压力参考匹配请求最近一次成功回包的输入用量，容量硬门禁仍按本地估算与保留额度执行。有安全旧前缀且达到压力阈值时，每次主决策至多尝试两次摘要。没有可压缩前缀且触发本地硬上限时，发送前报告容量失败。[Web 入口](../../src/personal_agent/adapters/web/routes/conversation.py#L183-L209) · [Runtime 入口](../../src/personal_agent/orchestration/runtime.py#L1009-L1011) · [装配](../../src/personal_agent/orchestration/runtime.py#L440-L469) · [压缩器构造](../../src/personal_agent/application/conversation/service.py#L292-L298) · [压力与硬上限处理](../../src/personal_agent/application/conversation/service.py#L2125-L2159) · [计量口径](../../src/personal_agent/application/conversation/history_compaction.py#L52-L74) · [硬门禁](../../src/personal_agent/infra/model_capacity.py#L104-L125)。

## 差距与最小验证

**源码已证实的差距是缺少发送后恢复入口。** 两边都由 Runtime 决定何时压缩。DeepSeek Harness 会消费已分类的服务方超限错误，并依据会话视图的替换进展决定是否重发。personalAgent 的容量拒绝属于发送前的本地判定。同样的 400 状态下，上游窗口超限与普通参数无效都退出这条主决策链。用户影响发生在本地放行、上游拒绝且旧历史可安全缩短的交集。真实部署中该交集的频率及恢复后的正确交付率待验证。

**归属取舍。** personalAgent 现有的 Journal、Artifact 和完整交互检查点已承担历史保真与授权恢复。若边界回放支持采用，可由现有 Provider Adapter 识别明确超限，由主决策复用 `HistoryCompactor` 和严格缩减检查，在当前 Turn 内至多重发一次。该候选只涉及失败分类与消费点，仍要遵守原预算及 Journal 请求身份。上游按最后作答路由选摘要模型，是为支持会话内切换服务方。当前 personalAgent 适配器对原生历史校验 `provider_host` 和 `model`，因此这一轮的候选沿用部署绑定。[Provider 绑定检查](../../src/personal_agent/infra/structured_model.py#L308-L321) · [外部参考的证据分级](../devSpec/change-evidence.md#6-外部参考的证据分级)。

**最小验证。** 用第 11 轮已归档的正式用户请求和相应历史，在现有 Web 入口做一次隔离 HTTP 传输回放。固定发出前的上下文和预算，使本地容量门禁允许发送且留有安全旧前缀。让替身仅对目标主请求第一次返回 HTTP 400 及 `context_length_exceeded`。基线应记录一次上游拒绝并返回 502。若验证恢复候选，观察一次摘要激活和同一步主请求重发，比较被拒请求与重发请求的输入估算、当轮问题和未决回执，检查此前工具执行次数保持不变，并由替身的后续合法响应走到同一 Turn 的交付出口。对照用相同 HTTP 状态返回普通参数错误，预期零次摘要和重发。记录三条路径的实际 HTTP 请求序列，取得这处差异后结束验证。该回放待执行，支持错误分支和交付路径的确定性判断，真实模型答题质量仍须另取证据。[原第 11 轮用户请求](../../.tmp/nyc23-rerun-20261119/t2/capture/turn-11.request.json)。
