# 面试收尾口径

可以用这段话收尾：

> 我这个项目真正想解决的不是“让 Agent 看起来什么都会”，而是让模型在目标和策略层保持开放，同时让权限、事务、状态和完成判断有系统边界。短期现场用 checkpoint，长期事实用 note/chunk，语义关系用 Graphiti，回答依据统一成 evidence；Executive 根据 Observation 逐轮决策，稳定事务由 Procedure 保护，具体能力由 Resolver 绑定；工具和 Agent 调用必须经过 Gateway、Policy、HITL 与 verifier。这样模型能改变方法，但不能扩大权限或绕过可恢复、可校验、可审计的工程边界。
