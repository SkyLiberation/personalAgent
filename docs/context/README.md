# 模型任务上下文索引

本目录按模型任务维护上下文模式：输入组成、事实来源、时间顺序、核验反馈、修复、跨轮及压缩边界。检索与维护使用[模型上下文管理 skill](../../.agents/skills/manage-model-context/SKILL.md)；上下文模式修改必须调用该 skill 并同步维护对应正文。

了解整体行为，先读[上下文管理](context-management.md)，按摘要压缩、裁剪、卸载、按需加载说明使用场景、介入时机和处理方式。

查询模型收到的拦截原因及修复指引，见 [Runtime 拦截反馈](runtime-feedback.md)。该文档按触发场景整理现有反馈，并记录可执行性审查结果。

| 模型任务 | 正文 | 范围与状态 |
| --- | --- | --- |
| Agent loop 主决策循环 | [Agent loop 上下文模式](agent-loop.md) | 本次用户指定的多轮任务模式与现有源码检索入口；实现差异和证据范围见正文 |
| 目标核验器 | [目标核验器上下文模式](goal-verifier.md) | 用户原话、目标维护结果、判决及 agent loop 修订后的复验；强制修复的实现差异见正文 |
| 目标遵循核验器 | [目标遵循核验器上下文模式](goal-compliance-verifier.md) | 以生效 goal 为判据，按同一条时间线接续动作、执行结果、回答、判决和实际修订 |

本文档集合不保存第二份会话历史。实际消息、目标、执行及核验事实由原 Journal 与对应责任主体拥有；权限与输入审计由 [CTX](../devSpec/context-memory-retrieval.md)拥有，生产行为及评测状态沿正文链接核对。
