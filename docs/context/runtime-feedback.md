# Runtime 拦截反馈

本文盘点 Runtime 在拦截动作、阻止交付或返回执行失败后交给模型的反馈。每项按触发场景、模型实际可见的信息和处理出口整理。固定文案按原意摘录，运行时才产生的字段值、异常详情和核验意见按其来源说明。审查以整次请求为单位，包括原动作、同批结果、当前工具声明及动态反馈。[上下文管理 skill](../../.agents/skills/manage-model-context/SKILL.md) · [上下文细则](../devSpec/context-memory-retrieval.md#12-system-prompt-与-context-的设计及问题分析)

盘点依据为本次工作树，基于提交 `88ae1c1`，包含工作树中的目标文稿与核验开关实现。静态枚举了 58 处对话 `DecisionFeedback` 构造点，并补查模型适配层、失败工具回执、语义核验、读取投影和停止路径。按调用方与模型消费者判断可达性。外部服务的动态错误按承载路径记录，具体内容取决于实际响应。

## 1. 反馈进入 Context 的位置

- **协议拒绝发生在执行前。** 整批未执行。有合法调用身份时，原调用及配对工具结果进入下一次主循环请求。原交换无法配对时，通过执行输入附上拒绝信息，并在适用分支保留被拒原响应。目标待维护时遇到未声明动作，改用原决策位置的单条系统消息，给出实际被拒名称、整批状态和当次允许动作。[原生历史投影](../../src/personal_agent/application/conversation/model_history.py) · [主请求构造](../../src/personal_agent/application/conversation/service.py)
- **业务准入可逐项拒绝。** 同批其他获准动作仍可能执行。被拒项、同批实际结果和未接纳的控制动作各自沿原调用回传。需要单独确认的知识操作混入其他业务动作时，运行系统在派发前拒绝整批业务动作。[动作准入与派发](../../src/personal_agent/application/conversation/service.py)
- **执行与核验反馈跟随实际观察。** 工具失败、资料不可用和核验退回可以进入主循环的执行输入或原交互后的系统反馈。仍然有效的失败及其修复按原时间顺序继承。任务核验开启时，目标核验与回答核验各自接收本职责的判决及后续修复。[上下文模式](agent-loop.md#3-角色历史与压缩边界) · [核验反馈组装](../../src/personal_agent/application/conversation/verification_context.py)
- **适配层修复使用原请求及同次被拒响应。** 结构化输出修复将原响应与校验信息放入下一次模型请求。有原生调用时保留配对，无合法调用身份时保留可用的原响应数据。主循环关闭适配层的自动动作修复额度，应用层负责该循环的动作纠正。[模型适配](../../src/personal_agent/infra/structured_model.py) · [主循环请求](../../src/personal_agent/application/conversation/service.py)

## 2. 模型输出和动作协议

| 出现场景 | 模型收到的反馈及处理出口 |
| --- | --- |
| 结构化 JSON 输出解析或类型校验失败，仍有输出修复额度 | 要求针对原任务重交完整 JSON 对象。附上校验详情及输出 Schema，保留实际被拒响应。修复文字要求遵守必填、类型、枚举和互斥约束。 |
| 原生结构化输出工具参数校验失败，仍有修复额度 | 指定本次唯一输出工具，要求重交完整参数。原调用、校验详情和当前工具 Schema 同时可见。两类结构化修复的校验文字均取前 2,000 个字符。 |
| 工具调用模式要求提交动作，但响应没有调用或参数不是合法 JSON。适配层分支有剩余额度且可续接 | 要求用当前已声明工具重交整批调用，参数为 JSON 对象，明确上一批未执行。附原响应及原因代码。当前主循环使用下列应用层反馈。 |
| 主循环提交未声明的动作名 | “动作 {实际名称} 不在当前请求的工具列表中。本批动作均未执行。”通用后续要求依据当前声明选择动作。待维护目标时，另外给出当次允许的目标维护动作，并说明业务工具暂不可用。 |
| 主循环动作协议校验失败 | 通用反馈为“本次动作集合不符合声明的交互协议”，说明整批未执行。附上可用的被拒动作、字段路径和错误类型，要求依据现有诊断及当前工具声明继续。可能涉及缺少调用、缺失或重复调用 ID、不支持的调用类型、参数 JSON 无效或参数不是对象。具体进入应用层或终止取决于适配层是否保留可交接的响应。 |
| 工作计划、业务工具、子 Agent、回答或目标动作参数不符合声明 | 普通动作使用上项通用反馈。Schema 类型错误可按实际字段路径、收到的类型和期望类型给出修复提示，数组被单属性对象包裹时指出实际数组所在位置。目标动作另附目标修复指引。业务校验错误仍按相应分支投影字段路径和错误类型，原参数从配对调用或被拒原件取得。 |
| 同批有多个工作计划，或目标操作、回答提交与其他动作混在一批 | 解码器分别拒绝多个计划以及要求独占的操作。交给模型时沿用通用动作协议反馈或目标修复反馈。具体的独占条件和计划数量原因留在解码异常描述中，反馈没有单独转交该描述。 |
| 动作定义重名、类型不受支持或原生响应无法恢复 | 有可交接响应时走协议拒绝或正文解码反馈。无可用响应或无法安全恢复时，由运行系统以输出无效或调用失败结束。定义及装配问题需要运行侧处理。 |

## 3. 目标、意图与工作计划

| 出现场景 | 模型收到的反馈及处理出口 |
| --- | --- |
| 本轮目标尚未维护就提出业务动作或普通答案，或无当前目标却试图沿用 | `goal_required`，说明目标操作未生效并附当前目标或空值。无目标时先提交完整目标，已有目标按本轮要求沿用或通过候选文稿修订。目标维护成功后继续业务。 |
| 读取或沿用目标传了多余参数 | 读取和沿用要求空对象。读取单独调用。沿用还要求已经存在目标且全文无需改动。确需改动时走文稿修订。 |
| 已有目标却提交整段新正文，或者候选文稿引用不属于本轮当前目标、版本、主体或可用文稿集合 | `goal_draft_invalid` 包含实际异常详情。按下一次请求的声明选择准备文稿、编辑现有候选或提交合法引用。 |
| 读取当前目标时无法生成候选文稿，例如文稿服务不可用或保存失败 | `goal_draft_unavailable` 与实际读取调用配对，说明依赖缺失或写入失败的原因。已有符合要求的文稿时可按声明提交。需要改稿且无法准备或写入时说明限制。 |
| 目标语义核验未通过 | `goal_verification_failed` 包含候选文稿引用、判决、逐项意见和修订建议。目标未生效。首次创建、准备文稿或编辑并提交的指引由下一次请求实际声明决定。 |
| 意图提取把后台继续工作认作用户要求，但来源不在最新用户消息或相位冲突 | 意图修订请求带上原提议和原用户消息，只允许重判后台要求及其来源、相位及其来源。确有要求时给出最新消息的合法行引用，否则取消该要求并清空对应来源。其余验收条件保持原值。 |
| 修订后后台要求仍无依据，或提取的验收条件无法绑定合法用户原文 | 主循环收到未接纳说明。后台要求无依据时继续当前对话，原文字允许请求用户明确后台要求。验收条件无依据时可请用户明确审稿条件，其他请求正常回答。明确要求后台继续且当前系统不支持时，由运行系统直接给限制说明。 |
| 部署需要语义核验，但相关能力未装配，且进入普通回答的降级分支 | 告知本部署没有核验能力，直接回答并说明未按要求核验。目标或回答核验开关关闭时按该运行的开关契约继续，回执注明未核验。 |

## 4. 工具、知识操作与委托准入

| 出现场景 | 模型收到的反馈及处理出口 |
| --- | --- |
| 将历史快照作为来源交给文件检查 | 给出被拒快照 ID 及仅供上下文恢复的限制。下一次请求只列出接受该 ID 的读搜工具。 |
| 将目标候选稿作为来源交给文件检查 | 给出被拒稿件 ID。目标候选属于任务解释，可按当轮声明读搜或编辑。 |
| Python 或实验工具缺本任务执行许可 | 指出未绑定获准环境，改用本任务可用能力或说明缺少环境。 |
| 调用 ID 已绑定一次已提交动作 | 指明已占用的调用身份。先使用已有结果，需要新操作时发起新调用。原生协议绑定调用身份。 |
| 同批提交完全相同的安全工具请求 | 指出同批首个动作 ID 及两次调用之间没有新观察。保留一项，观察后再决定是否需要不同的后续请求。 |
| 读取、搜索、知识查询、一般工具或子 Agent 未装配或当前不可用 | 指明实际工具或 Agent 名称，要求选择可用能力或如实说明限制。部分专用知识入口只给出说明限制的出口。 |
| 专用知识动作、文件读搜或已登记工具参数校验失败 | 保留原调用和异常详情，要求只改参数以满足本次声明的 Schema。可修复程度取决于具体异常是否写出字段、错误值及约束。 |
| 文件引用不在当前任务输入或已提交回执允许的集合 | 要求使用当前输入或已提交回执提供的确切 `resource_id`。 |
| 相同抓取请求已有外置结果，又重复抓取 | 指出相同请求已产生的原件 ID。本次请求若声明了允许该 ID 的读取或搜索工具，反馈给出实际调用名和参数。没有可用动作时说明边界。 |
| 当前交互已有成功的个人知识检索或知识清单，又重复调用 | 要求消费当前成功的检索或清单结果继续工作。 |
| 保存知识或准备删除知识与其他动作并发提出 | 给出实际动作数量，单独重提已配对的知识操作，等待用户确认。 |
| 保存所选文字为空、不是已有用户消息中的精确片段，或来源重复 | 给出具体选段位置、来源消息索引和合法用户索引。选取该用户消息中的非空连续原文。 |
| 准备删除的知识 ID 未在当前主体的清单中出现 | 给出未找到的 ID。已有清单时复用其结果。尚未取得清单且读、删均已声明时，使用当次工具名查找并单独提议匹配的条目。没有匹配项时说明限制或澄清。 |
| 保存或删除能力没有装配 | 如实说明无法保存或准备删除，避免宣称操作已完成。 |
| 知识等应用操作的业务校验拒绝，或缺少业务输入 | 返回实际异常文字。要求说明拒绝或询问缺失业务输入，保持用户目标。 |
| 同一 Agent 已返回产物，又重复委托 | 先使用已有产物综合。确需独立下游任务时，选择不同可用 Agent 并绑定已观察的产物引用。 |
| 已有成功产物，但后续委托没有绑定该产物 | 要求为真实依赖任务填写已提供的产物引用，否则综合现有成果。 |
| 本批剩余工具或 Agent 调用额度不足 | 指明耗尽的额度类别，提示停止或请求追加。全局预算已经达到上限时运行系统可直接结束，未必存在下一次模型调用。 |

## 5. 原件、执行结果与治理拦截

以下反馈沿工具或委托结果返回。运行系统保留动作身份、状态和具体结果。动态错误可能来自确定性校验、执行环境或外部服务。已注册能力是否能进入当前模型请求，仍由当次工具声明与执行入口决定。

| 出现场景 | 模型收到的反馈及处理出口 |
| --- | --- |
| 已提交的附件或原件无法恢复 | 给出具体资源引用，说明原件不可用且未替换。使用仍可用原件继续，恢复后再读，或如实说明缺失。 |
| 工具长结果被外置，或保存原件失败 | 回传原始和省略量、可读资源引用或不可用原因。已有引用时按同一资源搜索和读取。保存失败的分支按实际错误说明缺失，不能用预览冒充全文。 |
| 试图交付，但本轮先前抓取的卸载输出没有被取回 | 指出当前不能以所提方式结束，并给出未读原件 ID。按下一次请求实际声明的动作提示用 `keyword` 搜索或按 `start_line` 读取。没有可用动作时说明边界。 |
| 读取或搜索的资源 ID 不可用、重复绑定、越权或快照版本不匹配 | 返回文件不在可读集合、对应多个确切引用、归属不符或快照不匹配。原调用提供请求 ID。找不到版本、原件不存在或原件不是可读 UTF-8 时返回对应异常，部分存储错误仅附异常类型和文字。 |
| 文件读取起始行或列越界 | 坐标预检先返回 “text position is beyond EOF” 或 “text position is beyond the line or inside a newline”。模型可见原请求位置，异常未带总行数或该行实际长度。带总行数的专用模板在此越界路径未被使用。 |
| 读取容量不足以同时返回正文和续读参数 | 报告输出容量不足，未说明可执行的调整或替代读取方式。 |
| 搜索命中位置超出原文、分页偏移超出匹配数、单条记录超容量 | 分别报告位置或分页错误。单条记录过大时给出按原资源读取的出口。偏移越界未返回实际命中数或可用起点。 |
| 读取或搜索成功但只返回局部窗口，或可编辑文稿匹配范围被截断 | 说明实际返回行列、续读参数、原文范围及是否截断。搜索命中可用于读取起点。匹配过多可缩小关键词。零命中和当前窗口结束均不证明全文已读。 |
| 文件检查或文稿写入被拒 | 检查历史快照、不可见资源及缺接受记录按各自错误返回。写入错误还包括文件名与媒体类型不符、大小超限、补丁基稿不属于允许集合、基稿格式不支持、位置越界、范围交叠或重复插入。反馈使用实际异常及原调用，大小相关文字给出 UTF-8 字节上限。 |
| Python 执行被拒或已执行但失败 | 缺授权、请求绑定不一致、输入所有者或长度不符、预算耗尽等返回实际原因。实际执行回执给出状态、退出码或诊断、程序和输入清单及可用输出引用。输出达到捕获上限、无效 UTF-8 或无法恢复时分别说明实际保留的字节和可读性。未知终态需核对原执行。 |
| 网页读取或搜索失败 | 按实际结果返回访问限制、无正文、上游抓取失败、临时网络错误或未交付结果。网页读取错误由工具声明、原 URL 与错误详情共同提供判断依据。搜索服务的动态错误沿工具失败回传。 |
| 图谱检索未装配或不可用，或指定的笔记、研究运行不可访问 | 分别回传“图谱未配置或未启用”“图谱检索不可用”、实际图谱错误、“未找到该用户可访问的笔记”或“未找到该用户的 Research run”。原调用提供被查 ID。反馈本身不提供替代材料或新的合法 ID。 |

## 8. 表述审查

判定依据是负责修复的下一次请求能否回答四个问题。哪项动作或字段被拦截，实际值或缺失事实是什么，违反了哪项具体条件，当前能采取什么合法处理。原调用或同次回执已经提供的信息可合并判断。对无可执行修复的限制，反馈应说明可采取的替代动作、所需的外部条件或结束方式。[拦截反馈规则](../../.agents/skills/manage-model-context/SKILL.md#2-快速定位实际上下文)

| 场景 | 模型可见表述或缺失 | 审查结果 |
| --- | --- | --- |
| 目标正文满足字符上限，但违反独立的 UTF-8 字节上限 | 目标正文校验能产生“超过 65,536 字节”的具体诊断。转交模型时只保留字段路径和 `value_error`。当前目标 Schema 表达字符上限，目标通用修复文字没有给出字节条件。 | **缺具体违规条件。** 模型能定位 `objective`，却收不到实际触发的字节约束。 |
| 一批提交多个工作计划，或目标维护、回答提交混入其他动作 | 解码器已知道“最多一个计划”或“必须独占”，转交时使用“动作集合不符合声明的交互协议”或通用目标修复要求。对应分支没有字段诊断。 | **具体原因在交接中丢失。** 原批次能说明模型做了什么，反馈仍需说明应拆批还是只保留一个计划。 |

| 读取行列或搜索分页越界 | “text position is beyond EOF”“text position is beyond the line or inside a newline”或“搜索结果分页偏移超出匹配记录数”。原调用提供错误值，反馈未提供相应的合法边界。 | **缺合法范围。** 读取可给实际总行数或行长度，搜索可给匹配记录数及可用偏移。 |

| 抽取的验收条件缺合法用户原文 | 提示“本次验收条件无法恢复到合法用户原文”，要求用户明确验收条件。当前反馈不附未接纳的具体条件或来源位置。 | **缺被拒对象。** 模型无法从这条反馈定位哪项条件需要澄清。 |

| MCP 远端响应标记为错误 | “MCP tool {工具身份} returned an error result.” 该分支未交接远端错误内容，也未说明可采取的下一步。 | **只给失败状态。** 需要按实际响应给出可公开的原因及合法处理，远端无可用细节时说明这一事实。 |
| 工具、读搜、Agent 或核验返回通用失败 | 分支仅转发异常文字或“工具未执行”“工具执行失败”等兜底消息。工具网关也有仅给“稍后再试”或执行超时秒数的文案。 | **按实际失败检查。** 具体异常可与原动作合用。只有兜底句或缺少合法下一步时，无法指导修复。 |

| `read_current_goal` 准备候选文稿失败 | 被拒动作写成 `maintain_goal`，仍给出通用文稿流程。 | 对应原读取调用，区分依赖缺失和实际写入失败，按现有候选或限制处理。 |
| 原生调用 ID 已绑定一次已提交动作 | 把 Runtime 管理的 `action_id` 列为可编辑参数。 | 先使用已提交结果，确需新操作时发起新的合法调用。 |
| 知识保存或删除被拦截 | 固定英文、内部工具名和共用来源说明缺少具体错误。 | 使用当前语言、实际位置和范围。删除指引引用当次声明的清单和删除工具，知识确认流程照常执行。 |

真实阶段与确定性反事实共通过 12 项，审查补充回放通过 8 项。对一个真实目标请求只替换修复指引，模型提交了合法的 `read_current_goal`。E14 和 E22 均通过正式入口验收，覆盖保存、删除、确认和相应副作用反事实。罕见拒绝场景的结论限定在所列回放和模型选择证据。[实施与验收](../optimization/completed/runtime-feedback-repair.md#目标修复和知识确认)
