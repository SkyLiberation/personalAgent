# Agent 开发面试题考点总结

从 2026-11-18 起收录各日定稿题组。按主题查找已考过的判断，通过日期链接和题号回查原题。每行记录一道题的主要考点及会改变答案的条件。[训练要求](requirements.md#选题与来源)

## Agent 循环、调度与会话控制

| 原题 | 考点 | 判断依据与处理 |
| --- | --- | --- |
| [11-18 第 1 题](2026-11-18.md) | 工具循环怎样判定有进展 | 用可核验的待交付缺项是否减少判断进展。换参数却返回同一证据仍算停滞，正常异步轮询按服务状态退避。换策略后仍未推进或预算耗尽时，停止并报告缺项。 |
| [11-19 第 1 题](2026-11-19.md) | 服务重启后如何接续会话和外部写入 | 按会话恢复用户目标，按原命令、派发记录和回执恢复具体操作。已成功则复用回执。已派发但结果未知时，查询权威状态或按原幂等契约处理，无法确认就保留未知。 |
| [11-19 第 2 题](2026-11-19.md) | 何时委派子 Agent 及怎样合并结果 | 子目标可独立验收且隔离或并行有收益时才委派。限制可见输入、共享写入和预算。父级验收每份产物，部分分支超时后保留合格结果并处理剩余缺项。 |
| [11-19 第 4 题](2026-11-19.md) | SSE 重连怎样恢复进度并避免重新提交 | 提交按请求 ID 判重，订阅按运行身份和已收事件 ID 补发。历史断档时读快照恢复界面。客户端断线不触发重跑。 |
| [11-20 第 3 题](2026-11-20.md) | 同批工具调用怎样并发和排序 | 检查数据依赖、共享资源写入、工具能力和下游并发限制。独立读可并行，独占写形成顺序屏障。后续参数依赖工具结果时，等结果回到模型再生成调用。 |
| [11-20 第 4 题](2026-11-20.md) | 工具超时后怎样决定是否自动重试 | 区分尚未启动、已确认停止和结果未知。只读调用可在预算内重试，写入按原操作 ID 和幂等契约核对。调用方停止等待不能证明远端已停止。 |
| [11-21 第 4 题](2026-11-21.md) | 运行中的补充指令在哪一步生效 | 区分当轮补充和下轮任务。按轮次及请求 ID 入队，在工具批结算后的安全边界消费。当轮旧工具结果仍可用，已执行写入保留原回执。 |
| [11-22 第 3 题](2026-11-22.md) | 主动停止怎样传播并留下可恢复状态 | 按运行身份向模型、工具和下一步调度传播取消。区分受理、模型流结束和已启动工具收尾。未派发项记为跳过，恢复读取已经取得的实际回执。 |
| [11-24 第 1 题](2026-11-24.md) | 批量工具调用何时值得交给程序 | 比较原生多工具调用和程序化调用。程序批量读取、按明确规则筛选和汇总，文件用途不明确时交模型判断。固定输入和权限，对照结果正确性、模型往返、输入量及耗时。 |
| [11-25 第 1 题](2026-11-25.md) | 宿主单步硬时限下怎样切分长工作流 | 将一次模型决策及其有界工具执行作为可独立调度的步骤，用已完成步骤的消息和工具结果推进后续轮次。单个操作也会超限时，再评估分块或以作业 ID 接续的异步执行。 |

## 上下文、工具结果与模型协议

| 原题 | 考点 | 判断依据与处理 |
| --- | --- | --- |
| [11-18 第 2 题](2026-11-18.md) | 怎样压缩整份上下文并继续原任务 | 预算包含完整请求和输出预留。先外置可重读的大结果，再压缩已配对的旧历史。保留当前目标、关键约束、未完成项和原件引用，并检查压缩后的大小和约束保真。 |
| [11-20 第 1 题](2026-11-20.md) | 工具参数在哪一层校验 | 运行时按当前工具声明校验调用身份和参数形状，能力服务再校验权限和业务条件。默认值在约定边界应用。失败反馈定位具体字段和原调用 ID。 |
| [11-21 第 1 题](2026-11-21.md) | 动态状态怎样进入请求并保住 Prompt 前缀缓存 | 对照相邻实发请求的第一处差异，将更新追加到稳定前缀之后。撤权及时更新工具声明。用缓存读量、首 Token 延迟和用户结果验收。 |
| [11-21 第 2 题](2026-11-21.md) | 单个超长工具结果怎样预览和重读 | 执行方保留完整原件，模型输入只含预算内的关键字段或首尾预览，以及能定位原件的引用。保留调用 ID、执行状态和截取边界。原件保存失败时说明可读范围。 |
| [11-21 第 3 题](2026-11-21.md) | 何时切到大上下文模型 | 确认是上下文超限、没有可消费结果且必要材料压缩后仍放不下，再核对备用路由的容量、授权和预算，按策略有界切换。工具 Schema 错误按协议问题处理。 |
| [11-24 第 3 题](2026-11-24.md) | 结构化模型响应怎样区分截断、坏结构和拒绝 | 先判提供方终态，再验 Schema 和业务绑定。`length` 需要可用的新输出额度才可重试。正常结束但缺字段可有界修复。明确拒绝停止消费，即使 HTTP 成功或正文可解析也按对应终态处理。 |

| [11-23 第 5 题](2026-11-23.md) | 相邻 Skill 怎样写触发条件并验证分流 | 按用户要的产出区分故障定位、已有方案验收和只查状态。用正例、近邻反例和留出问法分别测选中、正文加载与任务交付，定位描述或执行问题。 |
