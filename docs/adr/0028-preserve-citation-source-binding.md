# ADR 0028：引用物化保留来源绑定

2026-09-18 决定，2026-11-18 随 Conversation 答复行坐标退役。原生成器从可见证据选择位置，由代码恢复原文和来源。[原坐标契约](0030-document-line-citation-identity.md) · [现行答复契约](0055-unified-conversation-answer.md)

## 背景与决定

正式研究第十八稿的两条 OpenAI 引文已有来源，核验投影却只保留正文。将来源身份、原文坐标与正文在同一投影中交付给核验。资源元数据来自有权限的实际执行记录，由完整资源版本或内联快照标识；未知 URL 保持未知。复用原读取、引用与核验边界，仅增加来源绑定和必要的投影。采用 Anthropic Citations 与 MCP Embedded Resources 的位置或 URI 和内容配对，详细依据保留在[问题记录](../optimization/citation-source-attribution.md)。

## 历史验证与退出

原固定状态的五个可能编号均恢复了来源，旧转换丢失来源。独立无据权限保证仍被拒。该证据覆盖局部交接，完整产品运行未复验。若出现来源错绑、正文改变或作用域扩大，回到实际执行输入与本次引用物化验证。[历史证据](../optimization/citation-source-attribution.md#确定性修复与验证)
