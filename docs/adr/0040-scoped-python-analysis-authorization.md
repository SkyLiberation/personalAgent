# ADR 0040：按对话明确授权 Python 分析的初版决定

2026-10-23 接入。专用 Python 工具以及对应许可由受控 Bash 工作区替换。[现行决策](0056-bash-workspace.md)

## 背景与决定

LongDS 首轮的实发工具表没有 Python，当时 Runtime 将该许可绑定到检索实验部署。改为在实际服务方支持及明确授权下开放 Python，冻结主体、对话、镜像、绝对到期和总额度。Journal 保存各轮的授权摘要与已提交结果，后续轮次只恢复同绑定事实。缺许可或绑定冲突时拒绝。

复用既有执行、Artifact 和沙箱边界，保持原研究实验部署独立。替代方案中的全局开放与按提示猜测权限无法提供相同的作用域保证。后继 Bash 独立定义其运行时和网络许可。[原适配与验收规格](../optimization/to_verify/python-data-analysis-tool.md)

## 历史验证

局部执行、停止及恢复已取证，完整用户结果及跨用户轮接续未通过。正式评分、工具可达性和各次停机证据按原运行身份保留。
