# ADR 0039：模型自主 Python 执行接入原工具循环

日期：2026-10-21。状态：接受并已实施；局部执行／恢复与自主模型消费已取证，统计分析整稿未通过。用户已授权整理整体研究设计后实现实验结果统计并局部验证；这不代表产品验收或发布通过。

## 背景与决定

真实E1的原件及搜索计数正确，报告却把dense52写成38；撤回的自动统计候选主计数正确，但仍有排名解释矛盾。当前检索候选入口只接受排名JSON，没有通用分析执行契约。按[整体设计](../optimization/to_verify/knowledge-decision-delivery.md#12-整体架构增强顺序与本轮切片)及[工具Spec](../optimization/to_verify/python-data-analysis-tool.md)增加独立 `execute_python`，让模型选择程序与合法输入，实际执行后消费反馈。代码计算、报告语义、正式评分及完成分别验收。

## 责任与边界

Conversation继续拥有目标和模型循环，原Journal是接受、Command和执行结果唯一写入口；Artifact拥有程序、输入和输出字节。新接受分支在派发前绑定不可变Command，使用原run权限、截止及与检索实验共享的原子额度预留。未知执行先核对，不重新启动。原沙箱迁移为唯一共享实现，原检索controller和新工具各自消费，不复制评分或业务完成协议。

Composition Root从当前许可部署映射只读执行Profile；Python协调及Port不依赖检索业务类型。容器只得到显式文件、固定Python环境及资源界限，不注入其他工具、凭证、宿主服务或业务写入口。输出仅成为数据，不能产生新的调用权或完成事实。

## 替代、复杂度与验证

直接读原件维护面最小，但当前真实报告已有误归属；固定统计注入已撤回；把分析挂到检索业务会限制计算用途；全面程序化工具编排引入当前未证明必要的嵌套副作用及恢复面。本切片只新增一个工具与执行协调协议，并迁移原沙箱，不建通用任务表或CodeAgent。外部实际装配比较见[工具参考](../agentRef/tool-execution-and-safety.md#91-代码执行与其他工具的架构关系)。

实施前封存真实action及原预算。工具Spec V1连续消费模型程序和实际输出，V2覆盖权限／限额／终态反事实，V3覆盖接受、派发及发布恢复和旧检索行为；局部组按预声明计数、集合和排名陈述判据验收。完整V4及自然压力压缩不在本轮执行。失败时按原判据停止并保留原件，不改提示后补样，不恢复自动统计注入。

本决定无兼容窗口，不新增规范例外；旧归档只读保持，现行内部消费者在同一变更迁移。工具无实际分析贡献或不能满足权限／恢复契约时撤回相应新增入口与主张，已有实验与历史压缩不受此决定授权扩大。

本轮跨日局部结果由[评测盘点](../evals/02-current-case-inventory.md#2026-10-21至22-模型自主python执行的局部验证)拥有。真实自主计算及程序原件保留；报告统计口径的独立失败没有否定已成立的执行事实，也没有取得完整研究或压缩收益。原组已停止，不以本ADR追加样本或付费授权。

## 2026-10-22 模型请求参数收敛

用户另行授权按外部源码复审方案推进优化。依[唯一Spec §3.1／3.2](../optimization/to_verify/python-data-analysis-tool.md#31-schema与描述的外部对照复审2026-10-22)，候选用同级code、program_ref和input_files替换program来源union及inputs；恰一来源不是null，输入列表显式提供。只改变模型／工具请求契约，冻结Command、执行终态、Receipt、原字节和摘要算法保持，新的载荷自然产生新的接受摘要。

当前配置data/interaction_runs没有持久记录，不设旧形状兼容或重写历史请求；封存实验按各自代码身份读取。首轮完成消费者迁移及真实两模式执行／恢复；10+10组中候选实际Python参数5/5合法，其余合法选择其他工具，曾因当时的调用频次门槛撤回。用户明确自主选择不是问题，并授权接回生产继续验证：本轮重新采用同一code／program_ref／input_files接口，不再以调用次数或比例决定接入、通过或回撤；旧封存判据和成绩不重写。跨模块事实owner及权限不转移，实施及新正式E1由[Spec §3.3](../optimization/to_verify/python-data-analysis-tool.md#33-接回生产链路并继续正式流程验证)拥有；首轮事实与成本见[评测盘点](../evals/02-current-case-inventory.md#2026-10-22-python-schema候选实施与覆盖不足)，不作统计语义或发布声明。
