## 背景与决定

真实 E1 搜索计数正确，报告却将 dense 52 写成 38。固定统计注入纠正主计数，仍产生排名解释矛盾。改由模型选择程序和合法输入，实际执行后消费结果，分别验证计算与报告语义。[原工具规格及结果](../optimization/to_verify/python-data-analysis-tool.md)

初版复用 Conversation 工具循环、原 Journal 与 Artifact。派发前冻结 Command、授权、输入、运行身份和额度；沙箱只接收许可文件和固定依赖，未知执行先对账。输出由执行系统记录，模型据此继续任务。与固定注入或任意执行平台相比，该切片只增加针对现有缺口的工具与协调。
