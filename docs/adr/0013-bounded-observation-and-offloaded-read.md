# ADR 0013：单次 Observation 的体积边界与原件重读

2026-07-31 决定。单条回执体积上限和原件保留沿用。2026-11-17 起，超限结果通过会话文件保存和重读，是否继续读取由模型依据任务决定。[会话文件与预算契约](../context/tool.md#会话文件替换决定)

## 背景与决定

E21 读取 GitHub 大文件时，单次返回 1,940,197 字符，实发 776,720 tokens，超过当时的 32,000 总量约束。完整结果直接物化，累计预算无法防止这次请求先超限。

Conversation 限制进入 Context 的回执体积。Artifact 保留原字节、来源与作用域，回执提供定位信息和有界预览。模型用独立搜索、分页读取工具决定取证范围。保存原文可保留自然行坐标，也避免截断预览或摘要替代引用依据。当前搜索和读取接口由会话文件契约维护，引用位置见 [ADR 0030](0030-document-line-citation-identity.md)。

## 历史验证与退出

旧阶段同一大文件的回执由 1,940,197 降至 12,138 字符，提交用量由 776,720 降至 26,424 tokens。早期重读先后暴露转义换行丢失自然行、命中行缺少上下文和重复抓取。CTX-001 的三份固定原件各约 469k 字符，最终通过精确重读取得对应随机事实。两组结果均按原代码与验证边界保留。[历史评测盘点](../evals/02-current-case-inventory.md)

旧读取入口由会话文件接口替换。逐份检查外置结果是否已读的交付门禁已退役；同输入的 GDP 交付回放与现行保存、续读、授权检查见[会话文件验证](../context/tool.md#4-已有验证)。
