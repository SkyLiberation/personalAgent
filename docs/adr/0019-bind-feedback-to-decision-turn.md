# ADR 0019：按模型决策回合统计反馈修复

## 背景与决定

同轮两个非法工具参数曾被算作两次模型尝试，在模型看到反馈之前终止。模型决策反馈通过 `decision_turn` 绑定原决策步骤；原反馈完整保存。非模型的前置反馈保持无决策归属。

进展后的重复检查按失败原因、计划版本和对应动作身份聚合不同决策步骤。同组跨两个步骤被拒绝才停止，同一批多条意见只占一个步骤。Journal 保存原始反馈，计数由其派生。复用原停止保护和恢复入口，删除按反馈条数计数的推导。[主循环及停止规则](../topics/runtime.md#conversation-loop)

## 验证与退出

原边界检查确认同批反馈可以送达、跨回合重复保护以及 Journal 重启恢复。两次正式目标仍因预算失败，工具获得修复机会与完整用户结果分别记录。参考 Agents SDK、Gemini CLI 将循环限制与并发工具数分离。若模型未收到合法纠错机会或恢复后失去停止保护，核对真实步骤身份与反馈记录。[原问题与结果](../optimization/revision-feedback-loop.md#53-按完整循环修复错误尝试计数并接入已证实改动)
