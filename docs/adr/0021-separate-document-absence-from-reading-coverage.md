# ADR 0021：分离文档缺项识别与读取覆盖判断

历史决定。独立缺项分类与覆盖拒绝于 2026-09-29 停用。[停用决定](0033-claim-deletion-and-document-absence-pause.md)

## 背景与原决定

普通核验曾在只读部分来源时放行“文档未规定”。候选让模型识别稿件是否对指定来源作出全文缺项声明，让代码从同版本的成功读取窗口计算覆盖。一次普通核验通过仍可被独立覆盖条件拒绝，新稿可补读并重新验证。[初版生产迁移](../optimization/document-absence.md#85-覆盖门禁接入真实读取事实与生产工具)

初版要求模型转录原句和来源，正式轨迹出现五次输出绑定失败。修订改用与固定来源顺序等长的布尔数组，由工具恢复身份。覆盖只包含实际完整返回的行，不合并版本和主体；未知总长或空来源不能证明读完。复用原核验工具和反馈循环，分类未命中时沿原整稿审查。[按序输出修订](../optimization/document-absence.md#104-按来源顺序返回缺项分类)

## 历史证据与退出

正式路径曾观察到覆盖拒绝、补读和重验。分类身份交接的改善与语义准确性分别判断，完整用户结果见当时的评测记录。后续 [ADR 0027](0027-model-owned-evidence-sufficiency.md)曾允许模型声明取证充分性后进入来源支持核验。两项附加机制均已停用，现行约束由整稿与引用支持承担。[历史验收](../evals/02-current-case-inventory.md#覆盖门禁生产迁移的验收边界)
