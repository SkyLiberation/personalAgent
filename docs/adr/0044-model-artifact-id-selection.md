# ADR 0044：模型以已公开的 Artifact ID 选择资源

普通 Artifact 检查与草稿编辑沿用 ID 选择；文件搜索、续读和 Bash 使用[会话文件契约](../context/tool.md#会话文件替换决定)。现行执行见 [ADR 0056](0056-bash-workspace.md)。

## 背景与决定

LongDS 两轮出现四次引用参数拒绝，原因是模型需要填写内部所有者、类型或版本。模型选择已公开 ID，Runtime 在当前获准集合中恢复完整引用，拒绝未知、歧义和越权输入。保留实际内容、作用域和版本绑定，复用原 Artifact 身份及写入口。拆除完整对象的模型输入后，工具回执仍保存执行事实。[原 ID 方案](../optimization/to_verify/python-data-analysis-tool.md#38-文件选择只提交现有-id2026-10-24)

## 历史验证与迁移

原 Python 参数候选 10/10，执行与文件交接通过。正式两轮均交付，仍出现 ID 抄写、媒体类型和程序问题；未验证完整 36 轮。旧运行继续由原配置说明，文件路径迁移不将旧成绩作为新工具证据。
