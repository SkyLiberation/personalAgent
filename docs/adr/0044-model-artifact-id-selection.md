# ADR 0044：模型以现有 Artifact ID 选择文件

状态：已接入并完成固定局部验收；参数阶段候选首次10/10，执行及文件交接通过；正式两轮均交付，仍有 ID 抄写／不支持媒体类型及程序错误，答案语义与36轮未验收。

## 问题与依据

真实 LongDS 两轮出现4次引用参数拒绝，模型被要求填写内部 owner／类型／revision。直接参数和原生历史没有消除该责任。用户授权继续简化并要求各设计先参考成熟实践；固定源码、架构及完整验收由 [Python Spec §3.8](../optimization/to_verify/python-data-analysis-tool.md#38-文件选择只提交现有-id2026-10-24)拥有。

## 决定与责任

公开文件选择输入复用 resource_id，草稿补丁使用 base_resource_id。Artifact 从当前获准集合恢复唯一完整 ResourceRef，未知、歧义、跨主体与非 Artifact 明确拒绝，不增加 ID 表或全局搜索。模型选择文件、代码和动作；Runtime 继续绑定身份、权限、版本及实际字节，Admission 不改写语义。

Python 已接受请求保存确切模型 ID，首次 Command 固化完整引用、原字节和 digest，恢复消费同一 Command。当前 Artifact 不可变 ID／版本1是适用前提，不默认为其他资源选择最新版本。内部 ResourceRef、来源、Receipt 及核验协议保留。

## 迁移、防护与退出

同步迁移 Python、读取、搜索、检查和草稿补丁输入及其全部当前消费者，不接受旧完整对象，不把字符串版本强转成整数。正式 Journal／Artifact 绑定先完整盘点；历史评测按原身份只读，新运行使用空根。发现旧正式持久化数据时先解决读取或迁移边界。

本次配置根的 Journal 快照为0；6个历史 producer_* 文件是无模型请求字段的旧 Artifact 元数据，现有读取行为不变，没有当前草稿补丁请求绑定需要改写。后续出现旧协议已接受记录时重新执行 REL 准入，不能把本次空 Journal 结论外推。

完整真实失败输入 baseline10／candidate10、原模型及预算验证；后续只跑已固定两轮流程，语义和36轮长任务不外推。失败撤回该简化，原生历史与直接参数保留；ADR 接受不等于生产通过。
