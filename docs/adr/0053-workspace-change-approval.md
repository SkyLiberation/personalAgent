# ADR 0053 工作区变更由应用持有确认与回执

## 背景

通用工具派发在确认前已经封闭。真实对话仍只能提出文字澄清，用户没有可审阅和批准的文件变更命令。Toolathlon 整理还涉及一批相互依赖的建目录和移动。

## 决定

部署把原始写映射专供文件工作区用例。应用以同一会话日志绑定已认证用户、原模型动作、不可变清单和提供方部署，在决策入口校验摘要。使用原调用的 Observation 接续对话。既有 Runtime、MCP 映射和策略引擎保留各自职责。[工作区变更契约与验收](../mcpDesign/README.md#523-工作区变更确认与接续)

## 取舍与防护

沿用本工程已存在的会话互斥、修订日志与派发前持久化顺序。逐项记录使部分执行或进程中断可辨认。远端缺少可核对的执行身份时，未决状态冻结当前绑定，重复确认仅返回已存回执。初始部署限定为一个受控、无链接、单写者工作区。去掉部署绑定即可撤下该业务动作，独立读取能力由原配置管理。
