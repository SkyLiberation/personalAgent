# ADR 0051 由组合根持有 MCP 客户端

状态为已接受的连接所有权决定。运行验收按 [MCP 接入 Spec](../mcpDesign/README.md) 记录。

## 背景

原批量工具工厂创建客户端，工具闭包持有客户端引用。宿主缺少统一关闭入口。真实 Time Server 停止后，旧客户端以既有握手状态隐式启动新进程，随后调用超时。

## 决定

`AgentService` 通过资源栈持有客户端。`bind_mcp_tools()` 按类型化部署配置连接、发现并调用现有单工具工厂。装配失败会回收此前已取得的连接。Web、CLI 和 worker 在停止或排空适用入口后关闭服务。Web 退出前停止消费新的飞书事件并等待已接收事件收尾。

stdio 进程失效后，同一客户端明确报告断线。恢复通过显式重启宿主实现，握手属于新客户端。HTTP 客户端在关闭时停止派发并清理本地会话引用。工具注册检查 canonical 名称和公开工具的模型名称冲突。现有工具准入和执行网关消费同一工具对象。

## 取舍与验证

把批量工厂留在工具层会保留资源所有权缺口。独立连接池或自动恢复会引入新状态和重新派发策略。采用显式所有权，只增加组合函数和宿主关闭路径。实施同时移除原批量工厂。V1、V2 分别验证真实调用、装配回收和断线语义。若后续运行需要自动恢复，先提供作用域和副作用安全重放的证据，再重新评估该决定。
