# ADR 0026：查询执行事实与来源证据分离

2026-09-17 决定。查询与来源交接保留，整套 Context 候选撤回。[查询交接固化](../optimization/completed/query-execution-handoff.md)

## 背景与决定

搜索结果缺少实际查询参数，不同搜索产生相同零匹配时无法追溯。由原执行入口保留真实参数，在请求内投影；引用只消费来源正文、身份、版本与坐标。复用原参数契约，避免从摘要重建查询或增设查询库。采用固定的 Gemini CLI、OpenHands 动作与结果配对方式。[问题与取舍](../optimization/evidence-acquisition.md#115-完整查询交接与-context-重组的正式接入验证)

## 结果与撤回

同题正式结果失败，53 个决策回合、54 次工具调用、2,194,884 已记录 tokens，最终返回未经请求的知识保存确认，无写入或答案。查询与引用保真检查成立。没有排除新消息组织对误选动作的影响，撤回本轮历史、反馈与提示重组，保留局部交接。原运行和脚手架错误按原身份存档。若参数身份丢失或进入引用正文，重开对应局部问题。
