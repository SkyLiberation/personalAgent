## 背景

最新 task2 六轮的原话和原生历史持续进入主模型，仍发生名单范围和必要条件替换，见[真实结果](../optimization/to_verify/verify_results/analysis-correctness.md#17-用户原话与持续约束候选的完整六轮)。已有独立分析路径不再生成 criteria，缺少后续可明确消费的当前目标；跨用户轮次的观察继承也未覆盖 Runtime 决策反馈。

## 决定及责任

2026-11-05 修订决定见[目标文稿契约](../optimization/to_verify/analysis-goal-maintenance.md#924-通过通用文稿编辑修订目标)。已有目标的全文重写替换为 Artifact 草稿编辑及按引用提交；首次创建、正式正文、核验与唯一 Journal 写入口保持。草稿由当前有效目标准备，后续稿件依赖已有补丁回执和父稿；仅当前执行且基准目标仍有效的稿件允许提交。工具展示、执行权限和读取恢复共同消费该绑定，核验拒绝不使草稿生效。下文的旧全文提交和读取说明属于此前实现；新身份的实际验证见对应 Spec，不把旧轨迹改标为新通过。

非读取目标操作在生效前交目标定义核验，回答提交按原配置交回答核验。原Journal保存完整交互，各核验只投影同职责的提交、判决及修订，均保留完整用户原话；主循环完整原生历史保持。当前目标可作为回答核验的任务材料，目标形成过程不进入回答核验。

在现有独立 Python direct 分析主循环使用 `maintain_goal` 完整创建或修订、`retain_goal({})` 沿用。原用户消息拥有要求，主模型拥有可纠正解释；Conversation校验结构、冻结输入、作用域和版本，并在目标定义核验通过后向原Journal提交唯一成功操作及 `verification_ref`。Journal验证该引用绑定本次目标原文和通过回执；拒绝仅反馈到原工具调用，不产生成功事实。当前目标及本轮前提由成功事实推导，不另建目标数据库或可写ready状态；不恢复来源索引。

每个用户轮次先完成经核验的目标工具往返，真实成功回执后开放业务动作和正常回答。普通模式通过独立的澄清操作向用户询问必要信息。限制或失败通过原提交工具交付，沿适用的核验流程处理。实际目标调用、核验、反馈和业务执行共享原生历史；Runtime反馈留在发生它的交互。当前目标独立于历史摘要恢复，顺序通过不代表用户目标已完成。[澄清与测试模式](../topics/runtime.md#回答测试模式)

模型Port的目标控制操作、原控制回执与Journal成功事实保持，恢复不重复修改。其他消费者不迁移，不恢复criteria或claims，不新增自动续跑调度。独立分析的direct/required只接入既有目标核验及原反馈循环，范围由[ADR 0047](0047-user-goal-verification-context.md)拥有。

## 防护、成本和依据

完整批次先校验，混合目标／业务调用整批拒绝且零写入。目标引用绑定原操作、版本及摘要，整轮输入绑定冻结消息，跨轮只继承精确匹配分支。同 run 恢复复用原成功事实及回执；取消索引按正式兼容期前的内部契约破坏式替换执行，旧冻结运行由其原源码解释，旧未完成请求或旧 digest 不嫁接新 Schema，不增加可写兼容字段。

当前提供完整写入、沿用和读取三个模型工具及两个职责内模块，分别拥有 typed 契约和转移规则；其余沿原 Conversation／Journal／Model Port。目标工具至少增加一次往返，通常增加一次主请求，纳入原预算。采用的 DeepSeek Harness、Codex、smolagents 固定源码、差异及真实消费者由子 Spec §2、§7 说明。

## 验证与退出

按子 Spec §8 执行完整真实阶段反事实和一次新空会话六轮，独立评分不回流 Runtime；目标解释、动作前提、回答结果和费用分别报告。实施身份 `.tmp/gm630/` 保存原源码、文档、dirty diff 及首段协议失败；一次有界引用修正后的 `.tmp/gm631/` 完成六轮，独立评分 2/6，实际结果与未覆盖项由子 Spec §9 引用的验证记录拥有。未满足语义验收，不声明目标偏离修复或发布通过。

失败按最早责任复审；不追加同义 Prompt 或无界补采，不自动恢复 criteria／核验器。撤回以本轮快照限定目标切片，保留用户原有改动和旧结果，不通过重写目标、评分或成功标准取得通过。

目标业务字段仍只有objective。目标核验只判断任务定义能否忠实指导执行，不能要求未来结果已存在；回答核验判断实际交付。两者使用相同最小逐项报告形状及原回执，各自选择专用提示、标准、历史和摘要；不新增模型阶段或可写事实。
