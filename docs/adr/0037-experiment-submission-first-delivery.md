# ADR 0037：实验研究提交与完成

- 状态：Accepted，2026-10-22按用户目标修正范围；旧文件交付证据保持原身份
- 范围：正式部署绑定的实验研究；普通对话和既有研究核验保持
- 唯一规格：[研究Spec §8.5](../optimization/to_verify/knowledge-decision-delivery.md#85-agent能力范围收回与删除计划)

## 问题与依据

用户先要求暂放claim／语义verifier，验证模型能否自主实验、消费实际结果并完成回答；随后明确用户资源下载、结果打包均不需要。旧方案把报告提交后自动发布清单／ZIP／报告副本以及110个资源下载纳入完成，上一轮真实E1已到Final，却在模型之后的批量下载429中被计作整体失败。该额外场景不属于当前Agent能力，删除而非继续完善下载或换成本地打包。

## 决定与责任

模型仍选择工具、程序、输入、必要实验和停止时机。SubmittedFinal与已发生用量先归Journal；Conversation恢复确切正文及原引用，实验Completion沿原owner检查实际成功、查询覆盖、开发／冻结／test次序、方案身份及权限；Python未结执行、输入与回执继续核对。明确缺口沿原反馈链返回，不代选方案、不补参数、不伪造语义通过。

检查通过直接提交并返回同一FinalMessage，提交后恢复及已完成返回均走相同完成规则。删除自动manifest／ZIP／报告Artifact发布、bundle builder装配和用户资源枚举；采集器停止逐资源下载。原工具生成的程序、排名、输入和双流保留内部Artifact引用，不因移除打包删除执行证据。已有通用Artifact路由由实际工具消费者使用，当前研究完成不调用下载。

不新增完成缓存、持久状态或运行模式。历史ResearchExperimentDelivery字段及清单DTO仅供已有离线封存读取者使用，生产不再创建发布绑定或依赖发布状态；旧归档只读，不重写旧评分、Trace或原源代码身份。CLI读者可供已有工程离线消费者读取旧材料，退出当前Agent验收。

## 验证与结论边界

使用原真实E1的0140提交后／发布前和0145已完成两份完整阶段状态，通过生产Web Composition Root各恢复一次：同一正文、resources为空、生成Artifact变化0，真实模型和实验新增均0、执行记录和原用量保持，进程停止。该证据覆盖确定性完成／恢复边界，不是新自然任务E2E；新自然请求去掉下载和打包义务，后续新E2E须单列身份。未运行单元测试或重开关闭模型组。

独立检查报告语义、证据驱动选择、权限／知识审计和自然压力压缩，不以文件数或下载成功代替能力。旧SQL健康关闭证据无法补造，语义仍按用户决定暂放；本决定不宣称完整研究、长任务或发布资格已通过。
