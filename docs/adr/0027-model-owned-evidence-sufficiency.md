# ADR 0027：允许模型声明本稿取证充分

历史决定。2026-09-29 停用独立文档缺项分类时，专用 `evidence_sufficiency` 一同退出。[停用决定](0033-claim-deletion-and-document-absence-pause.md)

## 背景与原决定

旧覆盖规则对所有命中且未完整读取的来源立即拒绝，模型无法按当前有限证据结束取证。原候选允许在本次 Final 提交充分性及理由。声明只改变是否继续进入来源支持和整稿核验，读取范围、引用权限及用户标准保持原事实。复用原核验入口和单次提交，不跨稿继承声明。外部参考和具体裁决由[取证记录 §116](../optimization/evidence-acquisition.md#116-由模型决定结束取证的契约验证)保留。

## 历史证据

原正式 target 在 64 个决策回合后返回 `limitation`，耗用 2,207,132 tokens。21 次核验失败中，17 次为来源支持拒绝，4 次为引句绑定错误。旧归档只存工具结果，无法判定覆盖分支是否命中或消费声明。另一条同代码复验的服务日志显示，4 次携带声明的稿件进入来源支持核验并被拒，证明路径可达，未取得有据稿件交付收益。退役原因和实验身份分别保留。
