# ADR 0038：按用户授权提前接入历史压缩

- 日期：2026-10-21
- 状态：实施例外。已有后续自然压力局部证据，完整产品验收未完成
- 例外复审／删除日期：2026-11-21。届时仍缺原先声明的自然压力证据，删除对应未验收生产压缩路径，保留原容量拒绝与证据
- 设计：[主循环 §3.11](../optimization/to_verify/conversation-loop-boundaries.md#311-context-压力与压缩)

## 依据与决定

早期真实 E1 没有触发自然容量拒绝，用户授权先接入压缩。例外仅涉及实现前的自然压力证据；原文、授权、计量、恢复与完成仍由既有契约保障。

2026-11-03 替换为按完整交互压缩。检查点按 run、已覆盖决策及源 digest 绑定有序前缀；Journal 拥有原交互和费用，Artifact 保留可授权读取的原件，摘要只改变模型输入。复用原 Model Port 与容量门禁。只有成功提交费用、实际缩小、来源仍匹配且版本未变时才激活候选。保存失败、失效或仍超容量时沿原边界停止。[完整交互压缩](../optimization/to_verify/analysis-goal-maintenance.md#920-结果卸载与完整交互压缩)

## 验证与退出

2026-10-21 首个摘要因输出全为 reasoning 且 `finish_reason=length` 停止，113,273 tokens，未激活检查点。事后费用从真实 SDK 异常对账。2026-10-22 历史非思考样本验证局部生成、消费与恢复，摘要仍沿用原错误，未证明语义保真。后续配置改为继承部署 thinking。[历史评测](../evals/02-current-case-inventory.md#2026-10-22-非思考摘要的局部验证)
