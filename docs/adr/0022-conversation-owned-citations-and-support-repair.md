# ADR 0022：成文引用试接入与逐字复制协议撤回

候选已撤回。遗留的责任决定是由生成器提交正文与依据，Verifier 判断提交的支持关系。[现行核验契约](../topics/verification-and-completion.md)

## 背景与原决定

整稿核验曾把相关主题或局部示例当作全称结论的依据。额外模型事后补引用仍漏掉相邻限定。原候选要求成文时用 `draft_quote` 逐字定位原句，附当前可见的执行或读取行。代码只恢复实际提交的原文，拒绝不可见来源和错误定位；局部支持拒绝与整稿验收沿原循环处理。

复用既有网关和核验入口。采用按引用取回依据并按对应文本核验的外部做法；本地新增边界主要是可见引用绑定和反馈。固定十次语义控制符合预期，受控循环证明同稿补引后可以重验。[候选过程与外部依据](../optimization/answer-object-mismatch.md#94-conversation-成文引用与缺证恢复的工程接入)

## 正式失败与退出

三次原正式任务均卡在逐字引用协议，未到达局部 Verifier。末次在加大预算后仍因相同错误停止。有界修正改善反馈交接，未消除完整正文和逐字副本不一致，最终撤回候选，生产净变化为 0。后继 [ADR 0023](0023-native-answer-segments-and-visible-citations.md)把引用附到原生正文段。[原始评测结果](../evals/02-current-case-inventory.md#成文引用与局部支持核验的迁移验证)
