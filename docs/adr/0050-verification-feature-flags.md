# ADR 0050：目标与结果核验的消融开关

日期：2026-11-05。状态：已实现，全开与全关的限定接入验证通过；完整收益实验未执行。唯一接入规格及证据记录由[实验组 1](../ablation/experiment.md#接入规格2026-11-05)拥有。

## 问题与决定

用户明确要求接入实验组 1 并默认开启目标与结果核验。已有 TOML 尚无运行消费者；旧 `AnswerResultConfig.verification` 仅控制回答，目标 Journal 强制要求核验通过，无法表达 B 臂。

以 typed feature flags 统一拥有两类核验的部署选择，默认开启。在原 Settings、Runtime、Conversation、回答模块和 Journal 中接入，不复制 Agent。删除旧回答核验配置，writer 选择保持独立。

## 责任与防护

目标维护仍由模型提议，Admission 只检查确定性契约；关闭目标核验时接纳事实不等于语义通过。Journal 在运行和对话边界绑定开关，禁止恢复时换臂。核验开启仍需真实回执；关闭不生成 passed、空成功回执或替代模型判断。回答核验独立开启时，只将未核验目标作为可纠正解释，用户原话继续拥有权威。

这是用户授权的机制消融装配；关闭任一核验的运行明确标记未完整核验，`release_eligible=false`，不替代完整 Product E2E 或发布证据。身份、权限、引用、执行事实和 required result contract 保持。收益须另按实验组固定条件比较，代码接入不构成收益结论。

## 复杂度、验证与退出

复用既有组合根、唯一循环、核验工具、目标操作和 Journal；新增 typed 配置及绑定，保留必要的开启／关闭分支，清理重复配置。配置、默认开启的真实阶段对照、正式入口两轮结果和关闭后的调用与事实分别验收，记录由接入规格拥有。

开关持续服务已登记的消融实验；移除或改变语义时按控制 skill 同步配置、消费者和实验组。发现开启路径回归、跨臂恢复或关闭伪造通过时停止对应实验，修正责任边界后按原验收恢复。此前 ADR 0041 的临时 `none` 配置由本决定替换，不再保留第二个核验写入口。
